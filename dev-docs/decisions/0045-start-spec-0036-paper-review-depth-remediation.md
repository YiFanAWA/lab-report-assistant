# 决策 0045：启动 SPEC 0036 论文解读深度整改

## 决策

项目负责人确认对 SPEC 0035 进行论文级整改。保留当前大样本案例和来源，将整改重点放在真实分析深度、论文结构和答辩叙事，而不是更换数据集或继续增加装饰性版式。

## 主要问题

- 当前只做了四类基础分组图，没有样本流程、缺失值、效应量、置信区间和多变量复核；
- PPT 只有 7 页，无法完整表达论文问题、数据来源、方法、结果和局限；
- 结果页使用通用解释框，未把图表与研究问题、统计方法和原论文口径逐一对应。

## 实施边界

- 不改变数据、证据、执行和交付物 owner；
- 不新增运行时依赖；
- 不把简化 Logistic 回归包装成原论文模型复现；
- 不输出医学诊疗建议；
- 所有分析图表和结果表来自真实 CSV 的本地计算，并保留来源与执行批次。

## 验收

以 `dev-docs/specs/0036-paper-review-depth-remediation.md` 的范围和验收口径为准。
