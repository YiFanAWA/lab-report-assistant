# 决策 0034：启动 SPEC 0025 PPT 三角色彩系统与深浅对比三明治结构

**日期：** 2026-07-31
**状态：** 已完成实现与验收（2026-07-31）
**版本：** V2.6.0
**关联 SPEC：** [SPEC 0025](../specs/0025-ppt-color-system-and-sandwich-layout.md)
**上游 SPEC：** [SPEC 0024](../specs/0024-ppt-renderer-layout-and-visual-hierarchy.md)（PPT 渲染器布局与视觉层次改进，已收口）、[SPEC 0011](../specs/0011-ppt-config-options.md)（PPT 配置选项）

## 一、背景

SPEC 0024 已建立 16:9 画布 + 空白版式 + 双栏布局 + 五级字号 + 单色主题的基础视觉体系，但端到端视觉测评发现两个结构性短板：

1. **单色平涂，缺乏色彩层次**：全片只用一个 `theme_color`，无辅助色做背景衬托、无强调色突出关键信息
2. **全浅色页面，缺乏深浅对比节奏**：标题区无背景色块、页脚只有浅灰细线，缺乏专业 PPT 的"三明治"层次感

SPEC 0025 在 SPEC 0024 基础上引入三角色彩系统和深浅对比三明治结构，解决上述短板。

## 二、决策

启动 SPEC 0025 PPT 三角色彩系统与深浅对比三明治结构切片。

### 核心改动

| 功能点 | 实现内容 |
| --- | --- |
| F1 三角色彩派生 | 从 `theme_color` 用 `colorsys` 标准库派生主色/辅助色/强调色 |
| F2 深色标题栏 | 内容页/图表页/总结页标题区改为主色背景栏 + 白色标题文字 |
| F3 深色页脚栏 | 所有页面页脚区改为主色背景栏 + 白色项目名和页码 |
| F4 辅助色背景 | 左栏文本区添加辅助色浅色背景矩形 |
| F5 强调色要点 | 左栏圆点标记和章节标题改用强调色 |
| F6 封面三明治收口 | 封面页底部增加主色窄条 |
| F7 对比度保障 | 深色栏白字、浅色区深字，主色亮度 > 0.60 时自动切换深色文字 |

### 约束

- **不引入新依赖**（使用 Python 标准库 `colorsys` + `python-pptx>=1.0.2`）
- **不改变 PptConfig 合同**（三字段不变，三色由算法派生）
- **不改变 PPT_THEME_COLORS 预设色板**（6 色不变）
- **不改变 API/service/Worker 接线**（`render()` 签名不变）
- **不改变 SPEC 0024 布局参数**（画布、双栏、字号、图表布局不变）
- **不修改数据库 schema**

### 三角色彩派生算法

| 角色 | 用途 | 派生方式 |
| --- | --- | --- |
| **主色（Primary）** | 标题栏/页脚栏背景、封面色块 | = `theme_color`（原值） |
| **辅助色（Auxiliary）** | 左栏背景衬托 | L=0.92, S=min(原S, 0.30) |
| **强调色（Accent）** | 圆点标记/章节标题 | H+0.5（互补色）, L=0.45, S=0.50-0.70；低饱和度(S<0.20)固定蓝色 |
| **标题文字色** | 标题栏/页脚栏文字 | L>0.60 用深灰，否则用白色 |

## 五、风险与缓解

| 风险 | 缓解措施 |
| --- | --- |
| 互补色派生不协调 | 强调色饱和度上限 70%，只用于小面积元素（圆点/标题） |
| 主色亮度边界 | 阈值 0.60 覆盖紫色，5 种预设深色统一用白字 |
| 辅助色背景与图表重叠 | 背景矩形严格限定在左栏范围内，右栏起始位置在左栏之外 |
| 测试回归 | 主色仍出现在标题栏/页脚栏背景，`_slide_has_color` 检查仍能找到主题色 |
