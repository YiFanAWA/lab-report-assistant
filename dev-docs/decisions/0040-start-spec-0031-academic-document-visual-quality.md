# 决策 0040：启动 SPEC 0031 论文级 Word/PPT 视觉质量切片

## 背景

项目负责人确认继续改善 Word/PPT 交付物，并要求呈现改进后的真实效果。SPEC 0030 的真实 PPT 预览证明基础主题已可用，但 Word 仍为默认直出，PPT 和图表仍缺少稳定的论文级图题、字体回退、信息层次与真实渲染验收。

## 决策

启动 [SPEC 0031](../specs/0031-academic-document-visual-quality.md)。

本切片采用以下主线：

1. 在现有 Word/PPT renderer owner 内建立统一视觉合同；
2. 修正图表生成层的字体、DPI、布局和标题策略；
3. 保持现有 API、Worker、数据库和渲染入口不变；
4. 以真实 `.docx/.pptx` 渲染结果作为视觉验收证据。

## 非目标

- 不更换整个 PPT/Word 技术栈；
- 不新增业务字段或数据库迁移；
- 不引入登录、协作或新的实验分析能力；
- 不把外部 Skill 源码直接复制进项目作为运行时业务依赖。
