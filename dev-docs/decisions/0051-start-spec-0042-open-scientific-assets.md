# 决策 0051：启动 SPEC 0042 开放许可科研图形资产库与科研示意图组件系统

**日期：** 2026-08-13  
**状态：** 已确认进入实现

## 背景

SPEC 0039—0041 已解决图形语义、论证合同和异构选图，但现有非统计图仍主要依赖矩形、文字和箭头。项目负责人要求接近正式论文中的实验流程、仪器路径和具象科研示意图，并希望后续人员能够复用本地组件。

## 决策

采用“开放许可资产注册表 + SVG 安全与许可证门禁 + 确定性科研示意图 renderer”的唯一主线：

- 只收录 Public Domain、CC0、MIT、Apache/BSD、CC BY 等允许当前用途的资产；
- BioRender、Mind the Graph 仅作风格参考，不绕过水印或付费/出版许可，不复制其受限组件；
- `server/app/modules/scientific_assets/` 是资产与许可证唯一 owner；
- `figure_planner.py` 继续拥有研究语义、节点、边与证据状态；
- renderer 只按结构化 spec 组合经过验证的组件，不让 DeepSeek 直接输出未经校验的 SVG/XML 或科研事实；
- 保存 SVG 真源和 Word/PPT 兼容派生物，使用哈希、来源和署名记录保持可审计；
- 首批优先 CC0/Public Domain，CC BY 必须自动生成署名。

## 并行执行

项目负责人明确要求分派多个 Luna 模型任务。主任务已将许可证审计、资产合同、渲染架构和验收设计拆分给 `gpt-5.6-luna` 隔离任务；这些任务只读审计，不直接修改主工作区。主任务负责最终 SPEC、架构判断、实现、diff 复核和验收。

## 停止条件

任何来源无法证明许可证、再分发权或署名要求时不得入库；任何 SVG 不能通过安全检查时不得转换或渲染；任何示意图暗示未经证实的医学机制或因果关系时不得进入论文成品。完成代码、视觉和授权验收后，仍需项目负责人确认视觉结果才能收口。
