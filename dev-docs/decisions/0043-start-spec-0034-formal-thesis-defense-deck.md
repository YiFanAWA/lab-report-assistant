# 决策 0043：登记 SPEC 0034 正式论文与高级答辩 PPT

## 决策

项目负责人已确认启动 SPEC 0034，目标是把当前交付物拆成两条清晰主线：正式论文式 Word/PDF，以及面向学术汇报/答辩的高级 PPT。本切片按确认后的 SPEC 进入实现。

## 原因

SPEC 0033 已解决章节语义与固定布局问题，但 Word/PDF 仍缺少正式论文前置结构、编号和目录合同，PPT 仍有“内容分页化”的简洁感。继续在单一布局中堆叠视觉装饰不能解决叙事和文档规范问题。

## 约束

- 不回档 SPEC 0030—0033 已完成的图表、主题、工作流和语义规划能力；
- 不改变实验数据、执行记录、证据来源和已确认大纲；
- 共享规划层拥有结构语义，Word/PDF/PPT renderer 仅做呈现；
- 项目负责人已确认 SPEC 0034，允许进入实现与验收；
- 当前环境若缺少 LibreOffice/Word，只能记录 DOCX/PDF 视觉验收缺口，不能虚报通过。

## 验收

实现与验收证据已回写至 `dev-docs/acceptance.md`，以 SPEC 0034 的文档结构、编号、追溯、PPT 叙事、逐页渲染和全量回归门禁为准。
