# 决策 0049：启动 SPEC 0040 期刊级论证图表与论文视觉语法改造

**日期：** 2026-08-13  
**状态：** 已确认进入实现并完成实现，待项目负责人确认收口

## 背景

SPEC 0039 已建立多语义图形系统，但正式论文仍需要回答“这张图支持什么主张、证据在哪里、结果是什么、不能推出什么”。如果只新增图形类别，容易得到形式上丰富、论证上松散的图表，并让观察性关联看起来像因果关系。

## 决策

接受“共享 `ArgumentPlan` + 期刊视觉语法 + Word/PDF 与 PPT 薄适配”为 SPEC 0040 唯一推荐路线：

- `figure_planner.py` 继续作为唯一语义 owner，并新增可校验的 `ArgumentPlan`；
- 三张核心逻辑图必须包含真实来源、数据口径、执行批次和解释边界；
- 统计图继续根据数据语义选择，不用逻辑图替代真实数值图；
- 变量关系图采用无交叉结构，明确标注观察性关联和协变量复核层；
- Word/PDF 输出完整论证元信息，PPT 使用现有 `pptxforge` 组件；证据链页采用图形主导的自适应版式，避免多面板图被通用主张条压缩成缩略图；
- 不新增运行时依赖，不修改数据库 schema、API、LLM Gateway、Worker 和产品边界。

## 实施闸

已完成“合同与负向测试 → 多面板案例真实图形 → Word/PDF/PPT 自适应适配 → 真实文件视觉验收”的顺序。当前 0040 成品以 `spec0040_argumentation.*` 命名，历史 SPEC 文件名保留用于回归夹具兼容。

## 停止条件

`ArgumentPlan` 通过定向与全量测试，三张核心论证图和统计图从真实执行产物生成，Word/PDF 与两套 PPT 真实视觉验收通过，且由项目负责人确认论文论证和视觉效果后收口。
