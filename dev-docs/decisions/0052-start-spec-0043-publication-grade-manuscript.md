# 决策 0052：启动 SPEC 0043 论文出版级结构、排版与交付物统一系统

**日期：** 2026-08-13  
**状态：** 已确认

## 决策

项目不回档，保留 SPEC 0039—0042 的图形语义、论证、异构编排、开放资产、安全和追溯能力；下一切片通过 `ManuscriptPlan + PublicationProfile` 将其纳入正式论文出版链，并用独立 `DefenseDeckPlan` 生成答辩 PPT。

`source_type` 不再决定论文章节。PDF 只由最终 DOCX 导出，不允许第二套正文布局。DeepSeek 只生成可校验文字候选，不拥有研究事实、统计、许可证、章节归属或排版合同。

## 原因

当前成品主要问题来自内容结构、出版字段、单一真源和交付物叙事，而不是缺少更多装饰。继续局部美化 renderer 会固化“验收报告套论文皮肤”的结构，无法达到正式论文阅读和答辩表达质量。

## 验证

使用当前公开 Diabetes 论文与 101,766 条数据案例进行压力测试：检查内容充分性、章节语义、动态字段、DOCX→PDF 单一链、论文图文节奏、12—15 页答辩叙事、逐页视觉质量与完整回归。
