# 决策 0050：启动 SPEC 0041 论文级异构图形编排与语义选图系统

**日期：** 2026-08-13  
**状态：** 已确认进入实现并完成实现，待项目负责人确认收口

## 背景

SPEC 0040 已经把证据链、多面板论证、数据管线和变量关系图纳入统一论证合同，但当前论文成品仍不能把“流程、关系、矩阵、统计、时间线和论证”按表达任务组合起来。继续只扩大多面板证据链，会把另一种固定模板替换成新的固定模板。

## 推荐决策

接受“现有 `FigurePlan`/`ChartPlan` 单一 owner + `FigureFamily` 与论文级编排合同 + renderer 薄适配”为 SPEC 0041 唯一路线：

- `figure_planner.py` 继续拥有图形语义、图形家族、数据前提、选择理由和拒绝候选；
- `chart_planner.py` 继续拥有数值图表类型选择，不由 PPT 或生成脚本临时决定；
- 同一篇论文可以同时使用流程图、关系图、矩阵/正式表格、统计图、时间线和证据论证图；
- 图形多样性必须服从数据与证据前提，不能通过装饰性节点或无来源连接制造复杂度；
- Word/PDF 和 PPT 消费同一套编排元数据，分别适配正式论文版式和答辩讲述版式；
- PPT 优先复用现有 `pptxforge` 组件，不新增运行时依赖，不改变 API、数据库、LLM Gateway、Worker 和产品边界。

## 实施结果

已按本决策完成“合同与负向测试 → 论文案例数据投影 → 双交付物适配 → 真实文件视觉验收”的实施顺序。当前实现覆盖五个图形家族，并保留矩阵与拒绝候选的结构化证据；全量后端测试 1173 项通过，Word/PDF 与两套 PPT 已生成并完成视觉抽检。

## 收口闸

项目负责人确认 SPEC 0041 成品视觉结果后，本决策进入最终收口。

## 停止条件

若某一图形家族缺少真实数据、来源或可读布局，必须保留结构化拒绝/降级原因，不用重复树图、重复四面板或装饰性占位图填充论文。实现完成后，需由项目负责人确认异构图形组合确实解决了“图形形式与表达任务不匹配”的问题，才能收口。
