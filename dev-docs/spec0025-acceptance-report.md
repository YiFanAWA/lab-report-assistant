## 一、概述

SPEC 0025 在 SPEC 0024（16:9 画布 + 空白版式 + 双栏布局 + 五级字号 + 单色主题）基础上，引入两个结构性改进：

1. **三角色彩系统**：从单一 `theme_color` 用 Python 标准库 `colorsys` 派生主色（Primary）、辅助色（Auxiliary）、强调色（Accent），解决 SPEC 0024 单色平涂缺乏色彩层次的问题。
2. **深浅对比三明治结构**：所有页面统一为"深色标题栏 → 浅色内容区 → 深色页脚栏"三层布局，解决 SPEC 0024 全浅色页面缺乏深浅对比节奏的问题。

### 2.2 核心方法

**三角色彩派生**（`_derive_color_palette`）：
- 使用 `colorsys.rgb_to_hls()` 和 `colorsys.hls_to_rgb()` 进行色彩空间转换
- 主色 = `theme_color` 原值
- 辅助色 = 高亮度（L=0.92）低饱和度（S≤0.30），浅色背景衬托
- 强调色 = 互补色相（H+0.5），中亮度（L=0.45）高饱和度（S=0.50-0.70）；低饱和度（S<0.20）固定蓝色 #2563EB
- 标题文字色 = 主色亮度 > 0.60 用深灰，否则用白色

**三明治结构常量**：
- `TITLE_BAR_HEIGHT = 1.0"`（标题栏高度）
- `FOOTER_BAR_HEIGHT = 0.5"`（页脚栏高度）
- `FOOTER_BAR_TOP = 7.0"`（页脚栏起始位置 = 画布高度 7.5" - 0.5"）
- `CONTENT_TOP = 1.2"`（内容区起始 = 标题栏 1.0" + 0.2" 间距）
- `CONTENT_BOTTOM = 6.8"`（内容区结束 = 页脚栏 7.0" - 0.2" 间距）
- `CONTENT_HEIGHT = 5.6"`（内容区高度）

## 三、SPEC 0024 vs SPEC 0025 对比

### 3.1 色彩系统对比

| 维度 | SPEC 0024（改进前） | SPEC 0025（改进后） |
| --- | --- | --- |
| **色彩数量** | 单色（仅 `theme_color`） | 三色（主色 + 辅助色 + 强调色，算法派生） |
| **标题栏背景** | 无背景色块（白色背景 + 主题色文字） | 主色背景栏 + 白色标题文字 |
| **页脚栏背景** | 无背景色块（浅灰细线分隔） | 主色背景栏 + 白色项目名和页码 |
| **左栏背景** | 无背景色（白色） | 辅助色浅色背景矩形衬托 |
| **要点标记** | 主题色圆点 | 强调色圆点（互补色，高区分度） |
| **章节标题** | 主题色文字 | 强调色文字 |
| **色彩协调性** | 单色平涂，缺乏层次 | 三色协调，主次分明 |

### 3.2 布局结构对比

| 维度 | SPEC 0024（改进前） | SPEC 0025（改进后） |
| --- | --- | --- |
| **页面层次** | 全浅色页面（白底 + 主题色点缀） | 三明治结构（深色 → 浅色 → 深色） |
| **标题区** | 无背景，主题色文字直接放在白色区域 | 主色全幅背景栏（高 1.0"），白色标题文字 |
| **内容区** | 白色背景，高 5.8" | 辅助色浅色背景（左栏），高 5.6" |
| **页脚区** | 浅灰细线 + 深灰文字 | 主色全幅背景栏（高 0.5"），白色文字 |
| **封面页** | 主题色色块（顶部） | 主题色色块（顶部）+ 主色窄条（底部），形成三明治收口 |
| **视觉节奏** | 平铺直叙，缺乏对比 | 深浅交替，专业感强 |

## 八、风险与缓解

| 风险 | 缓解措施 |
| --- | --- |
| 互补色派生不协调 | 强调色饱和度上限 70%，只用于小面积元素（圆点/标题） |

| 测试回归 | 主色仍出现在标题栏/页脚栏背景，`_slide_has_color` 检查仍能找到主题色 |
