SPEC 0027 网格布局演示

本页面演示 PptRenderer 在不同图表数量下的自适应布局行为， 使用生产代码 PptRenderer.render() 生成。

布局规则（SPEC 0024/0027）：
  • 1 张图表 → _place_chart_centered 单图居中（8" 宽）
  • 2 张图表 → _place_chart_side_by_side 双图并排（1×2 Grid，5.8" 宽/图）
  • 3 张图表 → _place_chart_three 上排 2 张 + 下排 1 张居中
  • 4 张图表 → _place_chart_grid 2×2 网格（3.8" 宽/图）
  • 超过 4 张 → 截断为前 4 张 + 底部截断注释

Grid 坐标计算验证

以下为 _GridHelper 在 2×2 网格中计算的坐标值（来自生产代码）：

单元格 Left Top Width Height 说明
cell(0,0) 左上 0.70" 1.50" 3.80" 2.30" 上排左
cell(0,1) 右上 6.80" 1.50" 3.80" 2.30" 上排右
cell(1,0) 左下 0.70" 4.00" 3.80" 2.30" 下排左
cell(1,1) 右下 6.80" 4.00" 3.80" 2.30" 下排右

网格参数：left=0.7", top=1.5", width=9.9", height=4.8", rows=2, cols=2, h_gap=2.3", v_gap=0.2"
计算：cell_w = (9.9 - 2.3×1) // 2 = 3.8", cell_h = (4.8 - 0.2×1) // 2 = 2.3"
