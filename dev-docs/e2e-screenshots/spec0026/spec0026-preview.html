SPEC 0026 四项视觉增强

① 渐变填充

封面顶部色块、标题栏、页脚栏改为线性渐变（主色 → 主色暗化），增强层次感和立体感。

fill.gradient() + gradient_angle=90

② 圆角矩形

左栏背景衬托改为圆角矩形（半径 0.05），柔化硬边缘，提升视觉精致度。

MSO_SHAPE.ROUNDED_RECTANGLE

③ 外阴影效果

右栏图表添加柔和外阴影（模糊半径 8pt，距离 4pt，方向 315°，不透明度 30%），增强层次感。

oxml: a:effectLst + a:outerShdw

④ 形状细边框

右栏图表添加辅助色 1pt 细边框，与左栏背景色呼应，形成色彩统一。

shape.line.color.rgb = auxiliary
