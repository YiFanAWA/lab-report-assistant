# SPEC 0036：论文解读深度整改

## 目标

针对 SPEC 0035“样本量大但分析层次不足、论文叙事过短、答辩 PPT 留白过多”的问题，将 Diabetes 130-US Hospitals 案例升级为论文级解读成品。

## 范围

- 保留 101,766 条公开住院记录和 Strack 等 2014 年开放论文，不更换案例；
- 增加原始样本与论文最终样本的筛选/口径对照；
- 增加缺失值质量分析、变量分布、分层结果和敏感性分组；
- 增加 HbA1c 检测组的风险差、优势比和置信区间；
- 增加可解释的简化多变量 Logistic 回归复核与森林图；
- Word 形成完整论文解读章节、结果表、图表和附录索引；
- PPT 扩展为约 12–15 页，形成问题→来源→样本→质量→方法→模型→结果→局限→结论叙事；
- 所有图表通过 `artifact_group` 与章节绑定，Word/PPT 共享同一份语义规划。

## 统计边界

- 本地分析使用公开原始 CSV 做描述性统计、二项比例置信区间、效应量和简化 Logistic 回归；
- 简化模型不等同于原论文最终模型，不宣称复现论文的样本筛选、交互项和全部协变量；
- 置信区间和 P 值只用于教学性复核，不作临床诊疗依据；
- 论文原始结果、本地原始数据结果和推断限制必须在成品中分栏或分节标明。

## 验收口径

- 真实 CSV 计算出样本量、缺失率、分组结果和回归结果，禁止固定假数据；
- 至少包含样本流程图、缺失值图、主要结果图、分层图、效应量/森林图和回归结果表；
- PPT 目标为 12–15 页，结果页每页最多 2 张图，标题不换行、图表不裁切；
- DOCX 可重新打开，包含摘要、关键词、目录、论文解读章节、结果表、图题、来源和附录；
- 后端全量测试、Alembic、前端 lint/build 通过；PPT 逐页 PNG 视觉检查通过；
- 缺少 LibreOffice/Word 时，必须明确记录 PDF 视觉转换缺口。
