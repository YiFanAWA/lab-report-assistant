### 2.3 关键决策：科学计算包作为 optional-dependencies 而非主 dependencies

**决策：** pandas/numpy/scipy/scikit-learn/matplotlib/psutil 声明在 `[project.optional-dependencies] analysis` 段，而非 `[project] dependencies` 主段。

**理由：**
- 按 AGENTS.md "V1 Python 执行必须是应用托管的受控环境"，科学计算包是**分析依赖**，由 Python 执行器在运行时调用，不是应用启动的硬依赖。
- 主 `dependencies` 中的 `openpyxl`（TD-007 已解决）是因为 `app/infrastructure/documents/dataset_parser.py` 直接 `import openpyxl`，是应用代码导入。pandas/numpy 等仅由用户代码（通过 `python_executor.py` 执行）使用，应用代码不直接导入。
- 作为可选依赖，用户可选择 `pip install -e .`（不安装分析包，LocalRule 模式可用）或 `pip install -e ".[analysis]"`（全功能，真实执行 Python 代码）。
- Docker 镜像必须安装 analysis 依赖（容器内需要执行用户代码），Dockerfile 改用 `pip install -e ".[analysis]"`。
- 不破坏现有 CI：SPEC 0015 CI 流水线已固定 `pip install openpyxl` 之外的科学计算包安装步骤，本轮改用 optional-dependencies 后 CI 也可受益（统一通过 `.[analysis]` 安装）。

**风险：** 用户开发环境如不执行 `pip install -e ".[analysis]"`，运行用户代码时会报 `ModuleNotFoundError: No module named 'pandas'`。这是预期行为（用户未安装分析包则不能执行分析代码），不是回归。

### 2.4 关键决策：不修改 AGENTS.md 规则条款

**决策：** TD-005 只修改 AGENTS.md "当前已知非阻断债务"章节的事实清单，不修改任何规则条款（推理闸、设计规则、版本控制等）。

**理由：**
- 按 AGENTS.md "宪法维护规则"：修改本文件前必须说明"为什么现有规则不够、改动会影响哪些 agent 行为、至少一个真实场景或压力测试如何验证改动有效"。
- TD-005 不涉及规则修改，只涉及"事实清单"更新（与 acceptance.md、README.md 同类文档回写性质一致）。
- "当前已知非阻断债务"章节是事实清单（描述当前债务状态），不是规则条款（约束 agent 行为）。更新事实清单不需要走宪法维护流程，但需要在 SPEC 中明确改动范围。
- 改动后 agent 行为不变：仍需先读 AGENTS.md 再读 dev-docs/README.md，仍需按阶段闸推进。

**压力测试：** 修改后，后续 agent 读 AGENTS.md 时不会看到"未暴露可调用的 in-app Browser 工具"的过时表述，避免误以为浏览器验收从未做。这不影响任何规则约束，只让事实清单与现状一致。

import argparse

LOG_FILE = r"d:\java_project\lab-report-assistant\dev-docs\worker-e2e-log.md"

def parse_args():
    """解析命令行参数。"""
    parser = argparse.ArgumentParser(description="Worker 端到端验证脚本")

        "--version",

        "--output",
        default=LOG_FILE,
        help=f"日志输出文件路径（默认 {LOG_FILE}）"
    )
    return parser.parse_args()

def main():
    args = parse_args()
    log_lines = []
    log_lines.append(log(f"# {args.version} Worker 端到端验证日志"))

- 同时支持 `--output` 参数让用户指定输出文件（避免覆盖历史日志）
